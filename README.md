# HAVA-DURUMU-UYGULAMASI
Proje genel olarak girilen şehrin hava durumunu bize verir. Aynı zamanda bize tekliflerde bulunur. Projede grafik ve havanın durumuna göre gif ortaya çıkarır.🔹 Kullanılan Teknolojiler:  Python  Gradio  Matplotlib  OpenWeatherMap API  🔹 Özellikler:  Şehir bazlı hava durumu sorgulama  Hissedilen sıcaklık ve detaylı rapor  Gif animasyonları
